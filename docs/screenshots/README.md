# Screenshot Guide

This folder is reserved for real app screenshots captured from the Android APK, web app, or sandbox build.

The case study currently uses GitHub-rendered SVG diagrams in `docs/figures/` so the project can be understood without requiring a device screenshot. For a final professor submission or portfolio page, add real screenshots here with these filenames:

| File | What to Capture |
|---|---|
| `live-tab.png` | Actual app showing live pothole markers. |
| `predicted-tab.png` | Predicted tab showing probability hotspots. |
| `three-d-nav.png` | 3D navigation tab with driver heading. |
| `high-risk-warning.png` | Temporary caution message in a high-risk area. |
| `sandbox-navigation.png` | Sandbox APK navigation simulation. |

Recommended capture size:

- Android emulator: Pixel 6 or Medium Phone profile.
- Browser: 1440px wide desktop screenshot.

After adding screenshots, embed them in `PROJECT_CASE_STUDY.md` near the App Views section.
